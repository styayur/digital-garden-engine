# Desktop Guide

## Technology choice

The desktop edition uses Tauri 2 and the system WebView2 runtime on Windows. This keeps the shell lighter than bundling a second Chromium runtime and lets the online and desktop versions share the same React editor.

The app does not maintain a second editor implementation.

## Development

Prerequisites:

- Node.js 22;
- Rust stable and Cargo;
- Windows 11 with WebView2;
- Visual Studio C++ build tools on Windows.

Run:

```bash
npm install
npm run desktop:dev
```

The Tauri configuration starts the Next.js development server and loads the same editor route.

## Production build

```bash
npm run desktop:build
```

The configuration runs `npm run build:example`, loads static output from `out/`, and creates an NSIS installer under:

```text
src-tauri/target/release/bundle/nsis/
```

The installer is unsigned unless the release environment supplies a Windows code-signing certificate.

## Local project directory

A desktop project directory may contain either:

```text
.rhizomaybor/project.json
```

or:

```text
rhizomaybor.project.json
```

Saving writes both forms for compatibility.

Generated website files are written under `dist/` beneath the selected directory.

## Filesystem constraints

Rust commands:

- require an absolute selected root;
- reject absolute file paths;
- reject parent traversal and non-normal path components;
- write only beneath the selected root;
- base64-decode generated bytes before writing.

Rust unit tests cover traversal rejection and valid nested output paths.

## Preview and build

The main editor preview is rendered inside the application. **Build**:

1. validates the project for website export;
2. saves the current project;
3. generates all static files;
4. writes them beneath `dist/`;
5. includes `export-manifest.json`.

## Recovery

Autosave still uses local browser storage inside the WebView. The project directory save is the durable copy. Users should keep project directories in a versioned backup system if they need full history beyond editor undo/redo.
