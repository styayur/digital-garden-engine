# Security Policy

## Supported versions

Security fixes are handled on the current minor release. Before v1.0.0, older preview versions may require an upgrade before a fix can be applied.

## Report a vulnerability

Do not open a public issue for a vulnerability or suspected privacy leak.

Use GitHub's private vulnerability reporting form:

https://github.com/styayur/digital-garden-engine/security/advisories/new

Include the affected version or commit, reproduction steps, expected impact and any suggested mitigation. Do not include real private notes, credentials or personal data in the report.

## Publication-boundary reports

Reports that draft or private content can cross into a public artifact are treated as security issues. If possible, reproduce the issue with the fictional canaries in `fixtures/content/`.
